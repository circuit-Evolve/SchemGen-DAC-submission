# SchemGen: dataset and generated schematics

This repository holds the 210-circuit evaluation set from the paper: each circuit's source image, its golden netlist, and the Xschem schematic that SchemGen generated from the image.

## Contents

```
images/            210 circuit figures (.png) from published papers
golden_netlists/   210 reference netlists, one per image
schematics/
  SchemGen/        210 schematics generated by SchemGen, one per image
```

All three folders use the same file names, apart from the extension. For circuit `<id>`:

- the source figure is `images/<id>.png`;
- the golden netlist is `golden_netlists/<id>.scs` (or `.sch`);
- the generated schematic is `schematics/SchemGen/<id>.sch`.

## Golden netlists

The golden netlists are the references the results are scored against. They come in two formats:

- **196 Spectre netlists** (`.scs`);
- **14 Xschem schematics** (`.sch`).

Both list the same information: device types, terminal connections and nets.

## Generated schematics

Each schematic is the final output of the full SchemGen flow:

1. deterministic reconstruction;
2. native Xschem generation;
3. VLM refinement: Claude Sonnet 5.5, medium effort, up to 3 rounds.

If the VLM edited a circuit, the file comes from its last accepted round. Otherwise it is the deterministic schematic. Every schematic passed Xschem netlisting and readback, which confirms that the saved schematic realizes the reconstructed connectivity.

## Opening the schematics

The schematics (Xschem 3.4.8) use these symbols:

- **SkyWater SKY130 PDK** (`sky130_fd_pr/...`): install the PDK and the Xschem symbol libraries that come with it.
- **Xschem `devices/`:** sources, supplies and pins, shipped with Xschem.

Open a schematic with `xschem schematics/SchemGen/<id>.sch`.
